# Saga release notes

This file is the stable entry point for Saga release information. Version-specific notes remain in their own files so historical release evidence is not rewritten when `main` advances.

## Current development line — Saga 0.53.0

Saga 0.53.0 makes machine control, robotics, and autonomous/drone systems the primary development focus while preserving the existing general-purpose language surface for tooling, telemetry, configuration, simulation, and integration.

See [`RELEASE_NOTES_0.53.0.md`](RELEASE_NOTES_0.53.0.md) for the development-milestone notes.

This development line is not a new frozen production release and does not imply physical HIL, target WCET, functional-safety, airworthiness, or other deployment-specific certification.

## Latest frozen release — Saga 0.50.0

Saga 0.50.0 remains the latest frozen release on the `release/0.50.0-production-ga` branch.

See [`RELEASE_NOTES_0.50.0.md`](RELEASE_NOTES_0.50.0.md) for the frozen release notes and evidence boundary.

## History

Older `RELEASE_NOTES_<version>.md` files are historical records for their named versions. They should not be interpreted as the current state of `main` unless that version is explicitly identified above.
